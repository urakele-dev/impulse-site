# Импульс — digital-студия

Одностраничный сайт digital-студии «Импульс». Сайт рассказывает об услугах студии, показывает кейсы и тарифы и принимает заявки через Netlify Function с доставкой в Telegram.

## Стек

- HTML5 с семантическими `header`, `main`, `section` и `footer`.
- CSS3: базовые стили и отдельные файлы секций в `css/`.
- Vanilla JavaScript без сборщика и внешних UI-фреймворков.
- Netlify Functions для безопасной отправки формы в Telegram.
- SVG-превью для Open Graph.

## Структура проекта

- `index.html` — единственная публичная страница и разметка секций.
- `css/` — стили шапки, первого экрана, услуг, процесса, портфолио, тарифов, FAQ, контактов и подвала.
- `js/main.js` — общие интерактивные сценарии: меню, шапка, год в подвале и прокрутка.
- `netlify/functions/send-telegram.js` — серверный обработчик заявки.
- `images/` — изображения и OG-превью.
- `backups/` — резервные копии файлов перед крупными изменениями.
- `PLAN.md` — план и состояние фаз проекта.
- `PROPOSALS.md` — предложения, ожидающие отдельного одобрения.
- `status.json` — служебный статус задач и журнал работ.

## Локальный запуск

Сайт можно открыть напрямую: запустите `index.html` в браузере. Для проверки Netlify Function нужен локальный сервер Netlify CLI, потому что адрес `/.netlify/functions/send-telegram` не работает при открытии файла через `file://`.

Пример с Netlify CLI:

```powershell
npx netlify-cli dev
```

После запуска откройте адрес, который покажет CLI, обычно `http://localhost:8888`.

### Локальные переменные окружения

Создайте локальный файл `.env` или задайте переменные средствами Netlify CLI:

```text
TG_BOT_TOKEN=токен_бота
TG_CHAT_ID=id_чата_получателя
```

Секреты нельзя добавлять в HTML, JavaScript клиентской части, Git или публичные сообщения. Файл с секретами не публикуйте и не передавайте в репозиторий.

## Публикация в Netlify

1. Откройте проект в Netlify или загрузите его через Netlify Drop.
2. В настройках сайта добавьте переменные окружения `TG_BOT_TOKEN` и `TG_CHAT_ID`.
3. Убедитесь, что функция находится по пути `netlify/functions/send-telegram.js`.
4. Опубликуйте изменения.
5. Отправьте тестовую заявку с телефона и проверьте получение сообщения в Telegram.
6. Проверьте публичную страницу, ссылки, мобильное меню и консоль браузера.

Текущий публичный адрес: <https://impulse-digital.netlify.app>.

## Поддержка и внесение изменений

### Контент

- Тексты услуг, кейсов и тарифов редактируйте в `index.html`.
- Контакты находятся в секции контактов в конце основного содержимого.
- Сохраняйте один `h1` на странице и правильную иерархию `h2`/`h3`.
- Для каждого нового изображения добавляйте содержательный `alt` на русском языке.
- После изменения текста проверяйте title, description и Open Graph-метаданные.

### Стили

- Для новой секции используйте отдельный файл в `css/` и подключайте его в `index.html`.
- Сохраняйте мобильный подход: сначала стили для небольших экранов, затем media-запросы.
- Используйте существующие цвета, радиусы карточек, интервалы и состояния hover/focus.
- Не добавляйте inline-стили и устаревшие HTML-теги.

### Форма и Telegram

- Клиентская форма отправляет JSON-запрос на `/.netlify/functions/send-telegram`.
- Обработчик ожидает поля `name`, `contact` и `task`.
- При проблемах сначала проверьте переменные `TG_BOT_TOKEN` и `TG_CHAT_ID` в Netlify.
- Затем проверьте логи Netlify Function и доступность Telegram API.
- Токен бота не меняйте без необходимости; при утечке немедленно отзовите его через BotFather и обновите переменную окружения.

### Резервные копии и Git

Перед изменением большого файла создайте копию в `backups/`. Каждое завершённое изменение фиксируйте отдельным понятным commit, например:

```text
git add .
git commit -m "Обновить тарифы"
```

Перед публикацией выполните проверку:

```text
git diff --check
git status
```

Новые кейсы и цены вносите только после подтверждения владельца проекта.
